# WellVantage

Welcome to WellVantage, a comprehensive platform designed to enhance gym management and user experience. This project provides a structured environment for administrators and users to manage gym-related functionalities.

## Overview


## Project Structure

- `public/`: Static assets including images and the logo.
- `src/`: Source code directory containing:
  - `assets/`: Project assets like SVGs.
  - `components/`: Reusable UI components.
  - `layouts/`: Layout files such as `HomeSidebarLayout.tsx`.
  - `lib/`: Utility libraries and helpers in `utils.ts`.
  - `modules/`: Feature-specific modules like `auth` and `gym`.
  - `pages/`: Different pages including `Login.tsx`, `Onboarding.tsx`, and `Register.tsx`.
  - `screens/profile/`: Profile-related screens like `Advertise.tsx` and `FAQ.tsx`.
  - `services/`: Service-related files including `api.ts`.
  - `store/`: State management files like `authStore.tsx`.
  - `styles/`: Styling files including `color.ts` and `global.css`.

## Getting Started

### Prerequisites

- Node.js
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd wellvantage
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
   or
   ```bash
   yarn install
   ```

### Running the Project

To start the development server:
```bash
npm run dev
```
or
```bash
yarn dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.
